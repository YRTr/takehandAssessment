Problem Statement: Self-Healing Automation Orchestrator

Current third-party automation tools (like Make.com) have strict rate limits and isolated workflows. You are tasked with building a custom, self-hosted API gateway that acts as a centralized automation hub.

Technical Requirements:

  • MERN Stack: Build a React interface that allows a user to define a "Trigger" and an "Action". Store these workflow configurations in MongoDB.
  • Python Scripting: Write a Python service that securely connects via `ftplib` to fetch remote assets, and utilizes `smtplib` to trigger notifications. The Python scripts must run dynamically based on the configuration stored in MongoDB.
  • AI Workflow Integration: The Node.js backend must intercept incoming payloads, route the text data through a lightweight local AI summarization endpoint (or a simulated mock), and pass the transformed data to the Python worker.
  • AWS: Deploy the Node.js API to AWS EC2 or Elastic Beanstalk. Ensure the environment is strictly locked down via Security Groups.

Hints & Guidelines

  • Design the MongoDB schema to handle polymorphic actions (e.g., distinguishing between an FTP task and an SMTP task).
  • Ensure the Python worker can gracefully handle API failures. Implement a retry mechanism with exponential backoff.
  • Your submission will be evaluated on security, architectural cleanliness, and proper separation of concerns between Node.js logic and Python execution.
